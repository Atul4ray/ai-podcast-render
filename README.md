# Atul Rey cloud renderer

This repository renders one Atul Rey Studio episode at a time with
[coldframe](https://github.com/Razee4315/coldframe). It is generated by
`npm run cloud:export` from the private studio repository.

Do not add secrets, databases, or server code here. An export contains only the
Remotion renderer, `public/episode.m4a`, and `props.json`, which includes the
episode title, transcript text, captions, and waveform.

Run a render from a `render/<episodeId>` branch:

    gh workflow run coldframe.yml --ref render/<episodeId> \
      -f composition=PodcastLandscape -f chunks=8

The MP4 is attached to the run as an artifact. Download it, then import and
validate it in the studio repository with `npm run cloud:import`.
